# personal-finance-tracker

## Project Overview

This proposed project is a cross-platform personal finance and expense management application for Android, iOS, and smartwatches running Wear OS and watchOS.

The application aims to help users manage their personal finances by recording income, expenses, and account balances across multiple financial accounts, including Cash, GCash, Maya, and bank accounts.

The planned functionality is intended to give users a clear understanding of their available money, where their money is being spent, and how much they can still spend within a specified budget period.

## Planned Key Features

### 1. Income and Expense Tracking

- Record income and expenses.
- Automatically update recorded account balances when income or expenses are added.
- Maintain a detailed transaction history.
- Categorize transactions to help users understand their spending habits.
- Allow users to edit and delete recorded transactions.

### 2. Financial Account Management

- Create and manage financial accounts, including Cash, GCash, Maya, and bank accounts.
- Set an initial balance for each account.
- Track individual and combined recorded account balances.
- Update balances based on recorded income and expenses.
- Allow manual balance adjustments.

### 3. Budget Planning and Management

- Create budgets with customizable start and end dates.
- Set spending limits for specific periods.
- Monitor expenses against allocated budgets.
- Track remaining budget amounts and spending progress.
- Support multiple budgets for different purposes or categories.

### 4. Dynamic Daily Spending Allowance

- Automatically calculate a recommended daily spending allowance based on the remaining budget and days left.
- Recalculate the daily spending allowance whenever expenses are recorded.
- Help users manage daily spending to stay within their budgets.
- Adjust calculations throughout the selected budget period.

### 5. Financial Reports and Insights

- Display summaries of income, expenses, and account balances.
- Visualize spending by category.
- Show spending trends over selected periods.
- Display budget progress and remaining allowances.
- Provide insights into financial habits.

### 6. Smartwatch Integration

- Support Wear OS and watchOS.
- Allow users to quickly record expenses through their smartwatch.
- Display account balances, remaining budgets, and daily spending allowances.
- Synchronize financial records between mobile and smartwatch applications.

### 7. Offline Access and Privacy

- Support offline expense tracking.
- Allow users to access their recorded financial information offline.
- Synchronize application records across supported devices when connectivity is available.
- Prioritize user privacy and financial data security.
